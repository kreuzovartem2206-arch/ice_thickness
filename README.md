# ice_thickness

Pipeline for daily sea-ice thickness mapping over the Russian Arctic using Level-2 satellite altimetry.

Development is done in feature branches. The current implementation combines Sentinel-3 SRAL Level-2 and CryoSat-2 Level-2 observations without using Level-4 input products.

## Experimental seven-day Sentinel-3 forecast

See [FORECAST_RU.md](FORECAST_RU.md) for archive download, publication-aware
training, chronological evaluation and CSV/GeoJSON/GeoTIFF output. This research
pipeline has not yet been trained or validated on a long real archive.
